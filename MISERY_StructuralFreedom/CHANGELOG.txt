MISERY Structural Freedom - Changelog
=====================================

1.0.1
-----
- Restarting this mod from the Mod Hub ("Restart changed mods") could crash the game: UE4SS removes a restarted mod's hooks on engine functions, but its hooks on the game's own functions stayed, still pointing into the old copy of the mod, and the next time the game ran one UE4SS crashed. They're now written down (hooks.txt in the mod's folder) and removed when the mod loads again in the same game session (shared GameHooks module).

1.0.0
-----
- First public release.
- Renamed project from the FreeBuild test name to Structural Freedom.
- Relaxes unsupported-grid rejection without creating arbitrary air-placement grids.
- Forces the master structural support result while preserving normal collision/placement systems.
- Uses lifecycle-driven hook installation only.
- No LoopAsync polling.
- No temporary ClientRestart hook.
- Adds structuralfreedomstatus and structuralfreedominstall diagnostics.
- Keeps legacy freebuildstatus/freebuildinstall aliases for pre-release testers.
- Includes English and Spanish installation/limitation documentation.
